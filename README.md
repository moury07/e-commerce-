# LuxeMart — GitHub Pages E-commerce Website

## Included
- 3 main pages: Home, Products, Cart
- Product details page
- 120 local SVG product images
- Search by product number/name/category
- Category filter
- Add-to-cart + localStorage cart
- Responsive mobile/desktop layout
- Animated background
- No backend required for the front-end demo

## GitHub Pages
1. Create a GitHub repository.
2. Upload ALL files/folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/ (root)**.
6. Save and wait for GitHub Pages to publish.

## Important
This is a static front-end store. For real orders/payments, connect a backend/payment gateway later.
To replace products, edit `products.js`. To replace product images, keep the image path in each product object.
